# Цветы для Дашули ♡

Романтическая открытка с семью цветами из моноширинных ASCII-символов. Canvas 2D выводит строки снизу вверх. Сначала растут стебли и листья, затем раскрываются бутоны. Ветер слегка изгибает каждый стебель, а отдельные лепестки плавно падают вниз.

## Запуск и открытие в браузере

Оставьте `index.html`, `style.css` и `script.js` в одной папке и дважды щёлкните по `index.html`. Можно также перетащить файл в окно браузера. Открытка работает локально и офлайн.

Для локального просмотра по HTTP при установленном Python 3 выполните команду из папки проекта.

```sh
python -m http.server 8000
```

Затем откройте [http://localhost:8000](http://localhost:8000) в браузере.

## Публикация на GitHub Pages

1. Создайте публичный репозиторий `flower-for-you` в своём личном аккаунте GitHub. Если отправляете существующий локальный коммит, оставьте новый репозиторий пустым.
2. Отправьте ветку `main` в репозиторий. Файлы `index.html`, `style.css`, `script.js` и `.nojekyll` должны быть в корне ветки.
3. В репозитории откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/(root)`. Нажмите **Save**.
4. Когда развёртывание завершится, откройте ссылку из раздела **Pages**. Стандартный адрес проекта имеет вид `https://ИМЯ-ПОЛЬЗОВАТЕЛЯ.github.io/flower-for-you/`.

GitHub Pages раздаёт эти файлы напрямую. `.nojekyll` отключает обработку Jekyll. CSS и JavaScript подключены относительными путями, поэтому открытка работает и в подпапке проекта.

[Документация GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)

## Обновление опубликованного сайта

Проверьте изменения, открыв `index.html` локально. Затем добавьте изменённые файлы и отправьте коммит в `main`. Например, после изменения только отрисовки букета выполните следующее.

```sh
git add script.js
git commit -m "Update bouquet"
git push origin main
```

GitHub Pages запустит новое развёртывание. Его статус виден во вкладке **Actions**.

## Файлы проекта

- `index.html` задаёт структуру открытки, описание букета и три строки послания.
- `style.css` отвечает за чёрный фон, адаптивную композицию, типографику и появление текста.
- `script.js` хранит текстовые узоры цветов и ленты, рисует символы через `fillText` и собирает анимацию букета. При `prefers-reduced-motion: reduce` букет сразу отображается в статичном виде.
- `README.md` содержит инструкции по запуску и публикации.
- `.nojekyll` указывает GitHub Pages публиковать статические файлы напрямую.
- `.gitignore` исключает локальные настройки и служебные файлы.
